# Project Development

## Implementation

The project was implemented using ServiceNow Flow Designer.

## Main Components

- Incident Workflow table
- Category field
- Subcategory field
- Short Description field
- Flow Designer
- Conditional branches
- Update Record actions
- Send Email action

## Automation

The flow analyzes the Short Description and automatically updates the Category and Subcategory according to the configured conditions.

An email notification is also generated for the caller after ticket creation.
