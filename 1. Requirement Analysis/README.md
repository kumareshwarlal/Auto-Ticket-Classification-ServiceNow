# Requirement Analysis

## Project Objective

To develop an automated IT ticket classification system using ServiceNow Flow Designer.

## Business Requirements

- Automatically classify IT tickets based on the issue description.
- Automatically assign Category and Subcategory.
- Support dependent Category and Subcategory selection.
- Send an automated email notification to the caller.
- Store ticket information in a structured format.
- Provide a scalable and maintainable solution.
